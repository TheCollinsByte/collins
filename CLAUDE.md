# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Static single-page portfolio site (GitHub Pages, `collins.github.io`). No frontend framework, no bundler for HTML — just `index.html` + compiled CSS/JS. Yarn is the package manager (yarn.lock present, not package-lock.json).

## Commands

- `yarn install` — install devDependencies (gulp toolchain)
- `yarn gulp` (or `npx gulp`) — default task: compiles `styles/styles.scss` → `styles/styles.css` (compressed) and `scripts/scripts.js` → `scripts/scripts.min.js` (uglified)
- `npx gulp watch` — watches `scripts/scripts.js` and `styles/styles.scss`, recompiles on change
- No test suite, no linter configured.

## Architecture

- `index.html` — entire site content, single page with anchor-linked sections (`#lead`, `#about`, `#experience`, `#skills`, ...). Nav links smooth-scroll via JS rather than native anchor jumps.
- `scripts/scripts.js` — source; hand-edit this file, never `scripts.min.js` (generated by gulp `scripts` task).
- `styles/styles.scss` — source; hand-edit this file, never `styles.css` (generated by gulp `styles` task). `styles/bootstrap.min.css` is a vendored dependency, not built from source.
- `scripts.js` responsibilities (DOMContentLoaded-scoped, no framework/state library):
  - Theme toggle: light/dark via `data-theme` attribute on `<html>`, persisted in `localStorage`, defaults to `prefers-color-scheme`.
  - Typewriter effect on `.typewriter` elements, driven by `data-type` (JSON array) and `data-period` attributes.
  - Smooth-scroll for in-page header nav links (links with class `no-scroll` are excluded).
  - `#experience-timeline` is progressively enhanced at runtime: child `<div>`s are wrapped into `.vtimeline-point`/`.vtimeline-content` structure and date badges are injected from each item's `data-date` attribute. Timeline markup in `index.html` should stay minimal (plain content divs with `data-date`); the JS builds the visual timeline DOM.
  - Mobile menu open/close toggles `active` class on `<header>` and `<body>`.
- 404 page (`404.html`) is a separate static file mirroring the main theme (light/dark support), served by GitHub Pages on unmatched routes.
- `robots.txt` / `sitemap.xml` at repo root for SEO/crawling — update `sitemap.xml` if page routes change.

## Editing conventions

- After changing `scripts/scripts.js` or `styles/styles.scss`, run `npx gulp` and commit the regenerated `.min.js`/`.css` outputs alongside the source — the site serves the compiled files directly (no CI build step).
- Deployment is via GitHub Pages directly off this repo — whatever is committed to the default branch is what's served.
